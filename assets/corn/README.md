## Что проверено по файлам

FBX — бинарный формат версии 7500. Содержит одну Geometry, одну Mesh Model SM_Prop_Plant_Corn_01_L и один материал lambert23. 377 управляющих вершин, 302 полигона: 94 треугольника и 208 четырёхугольников; после обычной триангуляции — 510 треугольников на растение. Это оценка исходной геометрии, а не замер импортированного MeshPart или производительности Roblox.

Габариты исходной геометрии X × Y × Z: около 82.058 × 218.627 × 85.562 в единицах FBX. Y — верхняя ось, UnitScaleFactor = 1. Минимальная Y = −9.727, максимальная Y = 208.899: pivot не гарантированно лежит на уровне почвы. Scale Unit = Centimeter — разумная стартовая настройка для UnitScaleFactor = 1; это предложение, итоговый рост в studs нужно проверить в Import Preview и затем на тестовом аватаре. Размер будущего поля остаётся TBD.

UV map1 присутствует: 453 UV-координаты, привязка ByPolygonVertex / IndexToDirect; диапазон U 0.047852–0.165815 и V 0.305012–0.378510. Есть слой vertex colors. PNG — валидный RGB8, 1254 × 1254, без alpha. Это общий цветовой атлас; правильное отображение конкретных областей на кукурузе проверяется в Studio. Самостоятельно менять UV, перерисовывать или обрезать атлас не следует.

В исходном FBX отсутствуют Texture и Video objects; путь к PNG не привязан к материалу. При импорте исходного FBX без подготовки этот PNG автоматически не связан с материалом. ## Ручной импорт в Studio

Импорт выполняется в остановленном Test. Существующее окружение и сохранённый .rbxl агент не изменяет.

1. Открыть File → Import (либо кнопку Import на Home), выбрать assets/corn/SM_Prop_Plant_Corn_01_L_textured.fbx. Проверить Import Preview и предупреждения. Включить Import Only As Model и Anchored, выключить Import as Package. Add to Workspace нужен для первоначального осмотра. Upload to Roblox можно отключить, если не нужен новый model asset в инвентаре; документация описывает этот переключатель как настройку инвентаря, а не гарантию полностью офлайн-импорта. Scale Unit и итоговую высоту проверить в preview. [Roblox Importer](https://create.roblox.com/docs/studio/importer).
2. Если встроенная текстура не появилась в Import Preview или после импорта: через File → Import выбрать assets/corn/01_roblax_style.png. После успешного импорта скопировать asset ID изображения. На импортированном MeshPart задать TextureID = rbxassetid://<ID изображения>. Если изображение пока не доступно, дождаться результата импорта/модерации; наличие файла на диске само по себе не создаёт TextureID. [Roblox: смена текстуры MeshPart](https://create.roblox.com/docs/reference/engine/classes/MeshPart).
3. Проверить, что изображение легло на UV правильно, растение видно с нужных сторон и оно не стало прозрачным. При необходимости проверить Ignore Vertex Colors / Make Double Sided в настройках объекта импортера; включать double sided только по результату осмотра. Первую высоту для тестового растения подбирает прототип, окончательная высота — по проверке обзорных прыжков.
4. Назвать импортированный Model или одиночный MeshPart CornPlantTemplate и переместить его в ServerStorage. Адаптер прототипа принимает обе формы; одиночный MeshPart можно также сгруппировать в Model. Проверить Archivable = true. У частей шаблона для прохода через поле: Anchored = true, CanCollide = false, CanTouch = false; CanQuery = false для визуальной растительности. После этого runtime может клонировать шаблон в свою временную модель Workspace. ServerStorage не реплицируется клиенту; клон становится видимым после помещения в Workspace. [Roblox ServerStorage](https://create.roblox.com/docs/reference/engine/classes/ServerStorage).

Ожидаемый результат ручного шага: ServerStorage/CornPlantTemplate (Model или MeshPart) содержит визуально проверенную кукурузу с назначенной текстурой. Сообщить готовность и, если текстура не совпала с ожиданиями, показать растение в viewport. Не копировать поле вручную: код прототипа использует только этот шаблон и создаёт растения внутри принадлежащего ему runtime-контейнера.

## Ограничения первого этапа

Исходники в этой папке не дают готовые MeshId/TextureID и не синхронизируются Rojo как часть мира. Основа игры остаётся solo PC, без persistence/магазина/публикации. Остальные объекты стенда создаются из Parts. Импорт одной модели и клонирование доступны по API Roblox; текущая сессия агента не имеет Studio MCP или управления native GUI, поэтому фактический импорт и визуальная проверка не выполнены.

510 треугольников × число растений — полезная стартовая оценка видимой геометрии: 1000 растений дают примерно 510 000 треугольников до оптимизаций движка. Допустимую плотность и обзор нужно определять Play-тестом на целевом ПК; одинаковая mesh/texture и отсутствие коллизий помогают держать стенд простым, но не заменяют замер.
