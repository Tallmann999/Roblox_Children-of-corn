# Движения чучела и сцена поимки

Автор разрешил эту следующую фичу, звуки позже. Solo Studio DEV, без новой постоянной геометрии, импортов, экономики или сетевых правил. Серверная охота, дистанции, скорость, LOS и капкан10sec сохраняются. Подвижные детали только у одного runtime NPC: отдельные руки/ноги, голова/шляпа/глаза. Клиент применяет небольшой procedural pose до30Hz/9частей; Root никогда не анимируется. Патруль — походка и повороты головы, chase — ускоренная походка и тянущиеся руки, trapped — попытки вырваться без движения Root. Оригинальный неподвижный авторский маркер сохраняется.

Обе поимки проходят существующее phase=caught длительностью1sec. Сервер фиксирует факт, историю, число попыток и captured root CFrame; hunt state capturing прекращает движение/захват и отменяет pending routes. Первая роняет ключ, сохраняет расходники, возвращает в тот же угол с защитой. Вторая после сцены завершает caught_out без награды. Abort/death/menu/retry/Stop отменяют старый переход по epoch. Request от клиента о capture/позе отсутствует.

round_snapshot расширен обязательным capture={id:целое0..2,remaining:0..1,frame:CFrame}; default0/0/identity. Id вместе с minimap.round_id уникален в рамках сеанса. Frame сообщается лишь после действительной поимки и не раскрывает ищущего NPC. Клиент проверяет числа, конечные компоненты и ортонормальный CFrame. monster_state теперь также capturing. Частые snapshots не продлевают сцену: частный клиентский deadline ограничен остатком сервера и1sec. Смена раунда, отсутствие caught, смерть/смена персонажа и истечение deadline очищают представление.

CaptureController92 создаёт одну распознанную локальную декоративную копию runtime Monster возле камеры и плавно приближает лицо; без звуков, строба и сильной тряски. Camera bindpriority Camera+1 временно управляет CFrame/FieldOfView. Movement:SetCaptureActive освобождает sprint/cursor/map и не сбрасывает camera в эту секунду; RoundHud скрывает мешающую caught карточку, затем показывает возврат/поражение. После завершения восстанавливаются прежние CameraType/Subject/FOV и актуальная камера живого персонажа. Камера чужого владельца/новый CurrentCamera не перезаписываются. Все части локальной копии anchored/no collision/query/touch; она удаляется при cleanup.

Обязательные проверки: capture only after servercatch; обе поимки/abort/death/retry/epoch; не продлеваемый deadline, camera restoration, streaming/unbind/rest poses, bounded NPC-only animation, сохранение всех авторских world/art/Lighting/rawTerrain и equality всех Sources. Реализованы69Sources. Сохранение только engine Ctrl+S/AutoRecovery с guard и резервной копией.

Ночная GPU проверка выявила перекрытие лица листом. Только локальная копия и её cinematic camera получают +4studs по локальнойY к подтверждённому frame; серверный Root и переданный frame сохраняются. Исходные9визуальных частей runtime NPC временно скрываются LocalTransparencyModifier с guarded restore, чтобы копии не мерцали поверх друг друга. Исправленный ночной preview показывает обе глаза и лицо без кукурузы перед ним. Preview10sec — отдельный контролируемый QA, игровая сцена остаётся1sec.
