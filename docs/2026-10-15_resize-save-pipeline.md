Неизменяемый baseline: `place/Children_of_corn.before-resize-yellow-20261015.rbxl`, 1028519 байт, SHA256 `c7015e55a7cf4a020fe0ae1e3d40d4c69c17faf10a8f01d8ce4379066c955fed`. Это последняя принятая сцена с 6844 экземплярами и 78 Sources. Новый pipeline не использует предыдущие world allowlists поверх уменьшенной карты.

`scripts/verify-resize-yellow-copy.py` читает точные engine bytes и фиксированный `scripts/resize-layout.json`. Допустимы только перечисленные свойства исходных экземпляров, удаление перечисленных декоративных растений, точные 75 Sources из `src` и 3 Sources из `assets/CornfieldFog`, а также прежние узкие метаданные редакторской камеры и четырёх корневых FilteredSelection. Новых экземпляров, service metadata, свойств, классов, имён или произвольных переносов нет. Идентичность сохранившегося мира, арт, Baseplate, остальные Lighting и raw Terrain проверяются отдельно; исходная зелёная модель ServerStorage сохраняется.

Удаление одноимённых растений меняет экспортные суффиксы `DistantCorn#N`. Поэтому проверка сначала сопоставляет экземпляры по исходному UniqueId и проверяет класс, настоящее Name и идентичность родителя. Затем она приводит экспортные пути и Ref к исходным идентичностям. Текстовый путь с перенумерованным суффиксом сам по себе не означает новый объект и не разрешает подмену одного растения другим.

Сохранённые ObjectValue в HiddenCornIndex могут ссылаться на удаляемые растения. В настоящей Studio Destroy оставил193ссылки на detachedлистья; installer теперь явно обнуляет эти Value в обратимой фазе перед Destroy. Узкий repair принимает только полное193knownlegacyсостояние и отвергает mixed/unknown. Разрешение относится только к явно перечисленным в manifest свойствам Value, где исходный Ref указывает на конкретное удаляемое растение, а целевой Ref равен null. Остальные ссылки сохраняются по идентичности целевого экземпляра. Общего исключения для Ref нет.

Числовые значения перечисленных world properties сравниваются после точного f32 round-trip: короткая XML-запись и исходное engine значение могут иметь разные десятичные представления. Ближайшее другое представимое f32, неизвестные URI, NaN и бесконечность отвергаются. Строки, Sources, binary attributes и прочие неизменяемые свойства не получают числовых допусков.

Если автор сохраняет рабочую сцену через Ctrl+S, достаточно read-only проверки:

```powershell
. ./scripts/use-project-tools.ps1
python scripts/verify-resize-yellow-copy.py place/Children_of_corn.before-resize-yellow-20261015.rbxl place/Children_of_corn.rbxl --report .artifacts/playtests/2026-10-15-resize-yellow/preservation.json
```
