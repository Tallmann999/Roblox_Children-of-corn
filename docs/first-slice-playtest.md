Дата: 2026-10-09. Статус: код подготовлен, игровые проверки Studio ещё не выполнены. Режим: один игрок на ПК, локальный Test. Основа ранее запущена пользователем: 2 services / 0 controllers без видимых ошибок основы.

## Что подготовлено

Сервер создаёт собственную временную площадку CornPrototypeRuntime во время Test. Исходные объекты мира и сохранённый .rbxl кодом не меняются. На площадке один старт, 15 мест поиска, три бочки из Parts, ворота и зона выхода. При наличии ServerStorage/CornPlantTemplate создаются 510 растений высотой 8 studs из предоставленного ассета; без него появляется предупреждение и остаётся площадка для проверки маршрута.

Доступен путь: меню → Начать → найти единственный случайно размещённый ключ → E подобрать → E открыть ворота → пройти за них → результат с +10 → Ещё раз / В меню. Временный баланс сохраняется между раундами до остановки Test. Смерть/Reset и «Завершить раунд» прерывают раунд без награды.

Камера первого лица, спринт, оживающее чучело, поимки, звук и атмосфера пока не реализованы. Эта проверка не подтверждает страх, обзор или длительность 7–10 минут. Размеры площадки предварительные; конечный размер карты остаётся решением автора после теста.

## Ближайший ручной шаг: импорт кукурузы

1. Останови текущий Test. В Studio выбери File → Import и файл [SM_Prop_Plant_Corn_01_L_textured.fbx](../assets/corn/SM_Prop_Plant_Corn_01_L_textured.fbx).
2. В preview проверь текстуру. Включи Import Only As Model и Anchored, выключи Import as Package; имя — CornPlantTemplate. Upload to Roblox можно выключить для отсутствия новой модели в инвентаре. Этот флажок не гарантирует импорт без сетевого соединения. Нажми Import. [Официальные настройки](https://create.roblox.com/docs/studio/importer).
3. Перенеси импортированный верхний Model или MeshPart в ServerStorage. Итоговый путь: ServerStorage/CornPlantTemplate. Проверь Archivable=true и сохрани сцену Ctrl+S.

Подготовленный FBX содержит привязку и встроенный PNG, геометрия/UV проверены; реальный результат импорта ещё не подтверждён. Запасной способ назначения изображения описан в [README ассета](../assets/corn/README.md).
