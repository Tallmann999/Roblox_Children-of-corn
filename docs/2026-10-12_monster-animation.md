# Процедурные движения одного чучела

Дата2026-10-12. До реализации контракт согласован в scarecrow-presentation.md. Solo Studio DEV, движения только9декоративных частей одного server-owned runtime CornMap/CornRoundRuntime/Monster. Root, физика/коллизии, авторское чучело-маркер, охота и поле не меняются. Звуки отложены.

Shared MonsterPose содержит Parts (имя/размер/цвет/материал), Rest (9root-relative CFrames) и Get(state,time,moving)→9CFrames. Root анимируется исключительно сервером. Патруль — умеренная противоположная походка и поиск головой; chase — более быстрые шаги и вытянутые руки; trapped — покачивание плеч и попытки освободить ноги без roottranslation; capturing — плавное протягивание рук/наклон головы для авторизованной секундной сцены. dormant/stopped/неизвестныйstate дают точный Rest. Head/Hat/Eyes получают одну общую трансформацию вокруг основания головы. Захватная локальная копия клиента использует ту же таблицу поз, без чтения текущего NPC.

MonsterAnimationController (Order80) связывается только с полным распознанным Monster: CornMonsterOwned=true, первичный Root и9именных декоративных Anchored частей; старый объединённый Arms/Leg либо unknownparts отказывается анимировать. Единственный начальный небольшой GetChildren проверяет комплект; никаких обходов карты/кукурузы. Именной fallback resolve2Hz сопровождается ChildAdded/Removed, ancestry и ownership/состояние signals для немедленного unbind. После unbind поза восстанавливается относительно актуального серверного Root, а не старого мирового CFrame. Root сам никогда не записывается.

Heartbeat ограничен30Hz/9partwrites. В dormant/stopped после однократного restrestore отсутствуют writes. Patrol/chase шагают лишь при фактическом изменении Root; неподвижный патруль может мягко искать головой, погоня держит руки впереди без имитации шагов. Trapped/capturing допускают локальное движение стоящегоRoot. При потере ownership/части/родителя, смене runtime/карты либо Destroy текущие относительные RestCFrames возвращаются точно, connections отключаются.

Проверки запланированы: настоящий Shared pose на Lune CFrame — группы голова/шляпа/глаза, фиксированные pivots, противоположная походка, конечность и boundedуглы, рест; настоящий Controller с signal adapter —30Hz/9writes/0Rootwrites, stationary movement, nofieldscans, streaming/unknown/manualrig rejection, replacement/ownership cleanup, current-root-relative restoration и отсутствие connectionleaks. Живой rendering/FPS acceptance выполняется отдельно в Children_of_corn.
