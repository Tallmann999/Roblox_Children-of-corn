# Постоянная карта: установка, ручные правки и передача

2026-10-09. Цель — редактируемый Workspace/CornMap размером 1200 × 1200 studs только в Children_of_corn. Постоянная карта установлена пользователем; первый Test выявил отсутствующий RoundSpawn и немедленное завершение раунда. Исправление и повторный Studio Test пока не подтверждены; этот документ описывает порядок проверки. Файл отдельной готовой копии сцены пока не создан и не обещан.

## Текущее исправление существующей карты

Рабочая сцена уже содержит CornMap. [Аудит](2026-10-09_project-audit.md) подтвердил: в сохранённом файле нет RoundSpawn, старый SpawnLocation находится под землёй новой карты. Для этой сцены использовать **scripts/repair-corn-scene.luau**; старый установщик при наличии карты завершается без обновления.

1. Открой правильную Children_of_corn.rbxl, нажми Stop, закрой вкладки скриптов в Studio.
2. Точная копия текущего файла перед ремонтом уже сохранена в place/Children_of_corn.before-spawn-fix.rbxl: 152 819 байт, SHA-256 df831a6af024f9d8b4667ff3b67974b8a3c0c541afb3a54e2bb4a0da7831274b. Дополнительные несохранённые ручные изменения сначала сохранить Ctrl+S.
3. Скопируй весь repair-corn-scene.luau в Command Bar и нажми Run. Во время построения общего слоя дождись завершения; он создаётся порциями.
4. После `ChildrenOfCorn scene repaired` нажми F на выделенном CornerSpawns/SW и Ctrl+S, затем F5.
5. В меню игрок должен находиться над полем; начать раунд и повторить несколько раз. Сервер выбирает один из четырёх углов. Проверить кукурузу рядом/вдалеке, ключ, ворота, выход и +10 один раз.

Карта и ручные координаты не пересоздаются. При повторе обновления существующие углы сохраняются. Старый нижний Workspace/SpawnLocation остаётся в сцене с Enabled=false; новые нейтральные SpawnLocations имеют Enabled=true. Сервер назначает Player.RespawnLocation выбранному углу. При отказе прочитай Output: открытые вкладки/неизвестные Sources/ручные объекты внутри собственных слоёв нельзя молча затереть.

После Save агент может выполнить: `python scripts/verify-scene-preservation.py place/Children_of_corn.before-spawn-fix.rbxl place/Children_of_corn.rbxl --corn-repair`. Этот режим разрешает только собственные слои кукурузы, map_version=2 и отключение прежнего нижнего спавна; исходная кукуруза, Terrain, дома, ворота, земля и слоты проверяются отдельно.

## Правильная сцена и установка

Рабочий файл: `D:\ROBLOX\My_Projects\Roblox_Children of Corn\place\Children_of_corn.rbxl`. Сцену New_+1 speed monkey для этих шагов не использовать. Rojo ChildrenOfCorn сейчас остановлен; подключать его к открытым окнам для установки карты не нужно.

Защищённый Command Bar установщик подготовлен и проверен по пути `scripts/install-editable-scene.luau`. Файловая проверка на копиях DataModel в памяти подтвердила маркеры Corn, отказ в Speed Monkey, сохранение импортированной кукурузы/исходных объектов, сохранение существующего CornMap, отказ при открытых вкладках скриптов/добавленных дочерних объектах GreyboxWorld и откат Sources при ошибке ассета. Использован ограниченный адаптер геометрии Lune; живую установку и Test это не подтверждает.

Порядок установки:

1. Открой именно Children_of_corn.rbxl; проверь имя и путь в заголовке Studio. Нажми Stop, выйди в Edit и закрой вкладки скриптов в редакторе Studio. Сервер синхронизации Rojo остановлен; подключение плагина не требуется.
2. До установки уже создана резервная копия place/Children_of_corn.before-editable.rbxl (105 095 байт, SHA-256 065eeeebf998cf396ef98486c80b7b8d084c956378997482c2345ea00af6e61d). Сохрани текущую правильную сцену; не перезаписывай эту исходную копию.
3. Открой scripts/install-editable-scene.luau, скопируй весь текст и вставь его в Command Bar этой Corn-сцены, затем нажми Enter или Run. Если он отказался, не обходи проверки: прочитай сообщение Output. Повторный запуск не должен перезаписывать ручной CornMap.
4. После сообщения `ChildrenOfCorn editable scene installed` нажми F: установщик уже выделил RoundSpawn. Новая земля находится на Y=80, поэтому прежний вид камеры может показывать только старый Baseplate. Если выделение потерялось, выбери Workspace/CornMap/RoundSpawn в Explorer и нажми F. Проверь Workspace/CornMap, Ground, KeySlots с 15 местами, EscapeGate, NoCornZones и Props; источник SM_Prop_Plant_Corn_01_L должен остаться в ServerStorage.
5. Сохрани сцену Ctrl+S. Перед дальнейшими ручными правками сравни сохранённый файл с резервной копией: проверка ниже должна подтвердить сохранность исходного мира и импорта. Затем запусти F5 и выполни [приёмку первого этапа](first-slice-playtest.md). После Test нажми Stop и убедись, что карта осталась в Edit.

При сообщении `Close this script tab before installation` закрой указанную вкладку кода в Studio и повтори весь установщик. При `GreyboxWorld contains extra objects` остановись: установщик сохранил дополнительные объекты и ничего не изменил. Открытые вкладки проверяются через [ScriptEditorService.FindScriptDocument](https://create.roblox.com/docs/reference/engine/classes/ScriptEditorService#FindScriptDocument), чтобы не затереть текст редактора.

Для файловой проверки из корня проекта: `python scripts/verify-scene-preservation.py place/Children_of_corn.before-editable.rbxl place/Children_of_corn.rbxl`. Скрипт только читает оба файла, допускает новые объекты карты/изменение трёх контейнеров кода, сравнивает исходные instances и отдельно неизвестные бинарные свойства Terrain. Сцену агент не пересериализует вне Studio; успешное сравнение не заменяет F5.

Оба Bootstrap требуют CornMap с атрибутом corn_project_id = children_of_corn и отказываются при маркерах Asmr_Base/ASMR_Models. До установки правильной карты ожидается предупреждение Inactive: editable CornMap missing or another game detected; интерфейс и управление Corn не запускаются. Это защитное поведение, а не подтверждение игрового теста.

Code-only `build/code-foundation.rbxlx` содержит только код. Открытие этого файла не переносит авторскую сцену и импортированные ассеты.

## Что можно двигать руками

Правки делать только после Stop, в Edit. Изменения во время Test обычно принадлежат тестовой симуляции и не заменяют сохранённую авторскую карту. Перед новой проверкой: Stop → правки → Save → F5. [Режимы Studio](https://create.roblox.com/docs/studio/testing-modes).

| Объект | Как править | Что сохранить |
|---|---|---|
| Ground | Земля поля, текущий X × Z = 1200 × 1200; можно менять материал/цвет | Anchored, горизонтальная поверхность, согласование с FieldZone и PlayBounds; наклоны/ступени сейчас не поддерживаются |
| FieldZone | Область посадки; горизонтальные положение/ориентация и размеры задают поле | Tag corn_field_zone; растения рассчитываются от её CFrame; не наклонять |
| PlayBounds | Допустимая область игрока, включая пространство за воротами | Tag corn_play_bounds; старт, все 15 слотов и выход внутри допустимой области |
| CornerSpawns | Двигать/поворачивать четыре SpawnLocation целиком на поверхности карты; направление внутрь поля | CornCornerSpawnsOwned=true на Folder; сохранять четыре уникальных spawn_id, tag corn_spawn, Enabled/Neutral/Anchored=true. Legacy RoundSpawn поддерживается только для прежних карт |
| KeySlots | Двигать существующие 15 слотов внутри соответствующих просветов | Tag corn_key_slot, непустые уникальные slot_id; доступность по земле, без стен и домов. Просвет автоматически рассчитывается вокруг актуального положения слота (радиус 6 studs) |
| NoCornZones | Менять положение, поворот и Size дополнительных зон без кукурузы: старт/декор; просветы ключа следуют за слотами автоматически | Зоны ворот ApproachClearance находятся внутри EscapeGate и переносятся вместе с ней; для нового сооружения добавляй зону вручную |
| Props | Двигать дома/бочки целой Model, менять их Parts и декор | Статичные Parts Anchored; дома — только декор/препятствия, без мест ключа. Для нового сооружения добавь подходящую NoCornZone |
| EscapeGate | Выбрать всю Model и перемещать/поворачивать вместе | Door, InteractionAnchor и ExitZone внутри; gate_id совпадает, перед воротами и за ними свободный проход |

Не удаляй KeySlots и не дублируй их идентификаторы: текущий этап требует ровно 15. При переносе слота область без кукурузы рассчитывается от его новой позиции; отдельную зону-спутник двигать не требуется. Новый просвет должен оставаться доступным, без дома или стены. Один случайный ключ создаёт раунд; вручную расставлять 15 игровых ключей не нужно.

Ворота двигай всей EscapeGate: Door задаёт препятствие, InteractionAnchor — сторону E-взаимодействия, ExitZone — подтверждённый выход за дверью. ApproachClearance, Header и ExitGround также остаются внутри этой Model. После переноса проверь, что забор/дом не перекрыл проход, ExitZone находится за воротами и внутри PlayBounds. Сегменты северной границы находятся отдельно в CornMap/Boundaries. При переносе ворот сдвинь/измени размеры этих сегментов, чтобы оставить проход; автоматическая перестройка забора не обещается.

Размер 1200 × 1200 выбран автором; изменение размера — отдельное решение с повторной проверкой доступности и длительности. Весь CornMap можно переносить как Model, сохраняя взаимное положение его объектов; карта должна оставаться горизонтальной.

## Кукуруза в Edit и Test

Источник импортированного растения хранится в ServerStorage/SM_Prop_Plant_Corn_01_L; альтернативное имя CornPlantTemplate поддерживается. Исходный размер и текстуру на месте не менять ради копирования поля. [Ассет и URI](../assets/corn/README.md).

EditorFieldOverview покрывает всю область карты укрупнёнными MeshParts кукурузы для общего вида и дальнего плана. EditorPreview даёт детальные растения возле выбора. В Test клиент создаёт отдельные растения высотой 8 studs с шагом 3 в радиусе около 85 studs. Он скрывает дальние крупные растения локально только там, где детальные группы уже готовы; дальние группы возвращаются при уходе. Ключ/ворота остаются серверными объектами. Частота кадров и качество подгрузки ещё требуют фактического теста.

Ручные растения и Props не должны удаляться при обновлении собственного EditorPreview. После изменения слотов/NoCornZones/FieldZone новый F5 проверяет обновлённую посадку. Для ограниченного предпросмотра в Edit можно после установки выбрать объект и вызвать в Command Bar `require(game.ServerScriptService.GameServer.Game.MapAuthoring).PreviewAtSelection()`; он обновляет только собственный EditorPreview примерно в радиусе 55 studs от выбранного объекта. Не сохраняй из Test видимые клиентские группы как замену постоянной карты.

## Передача тестировщику

После установки и проверки:

1. Нажми Stop и сохрани .rbxl с картой, актуальными GameShared/GameServer/GameClient и импортом в ServerStorage.
2. Передай этот сохранённый .rbxl. Тестировщик открывает его в Roblox Studio под своей учётной записью и запускает F5; Rojo, Rokit и исходники репозитория для такого теста не требуются.
3. Проверь загрузку mesh `104111861186519` и texture `137803536172445` у тестировщика. Сцена сохраняет их URI, но доступность/разрешения и загрузка облачных ассетов должны работать для его аккаунта. При ошибке загрузки проверь доступ к ассетам и Output.
4. Передай вместе [первый тест](first-slice-playtest.md) и попроси записать результат, ошибки Output, видимость растений и FPS на фактическом ПК.

Это передача локальной сцены для Studio Test, без публикации Experience. Сохранённый .rbxl с облачными mesh/texture не является гарантией полностью офлайн-игры: нужен доступ к Roblox Studio и необходимым ресурсам. [Roblox: ассеты проекта](https://create.roblox.com/docs/projects).

После переноса домов/слотов/углов обнови общий слой в Edit: `require(game.ServerScriptService.GameServer.Game.MapAuthoring).RebuildOverview(game.Workspace.CornMap)`. Для детальной области выбери объект и вызови PreviewAtSelection, затем Save. Собственные EditorPreview/EditorFieldOverview — генерируемые слои; ручные растения помещай отдельно, например в Props.
