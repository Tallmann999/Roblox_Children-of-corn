Исторический A/B этап: после этой проверки автор окончательно выбрал второй звук для всех игроков и монстров. Кнопки и comparison API удалены; актуальная реализация и её отдельная приёмка описаны в [непрерывном шелесте](2026-10-15_continuous-rustle.md). Этот A/B Play не заменяет проверку трёх пространственных NPC loops. Файл сцены A/B-версией отдельно не сохранялся: disk baseline оставался489af64f… до итогового обновления.

Локальный solo PC MVP, текущий ночной режим. Код подготовлен после принятого сохранения630/жёлтой кукурузы489af64fb7f36bdfd7756f1e1d701324c6f202cf931422cf91c72be476a9965d (996617байт/4160instances/78Sources). Изменяются только пять существующих Sources: AudioController, MovementController, RoundAudio, AudioRules, AudioAssets. Постоянный мир, Lighting, импортированный арт, Terrain, remotes, предметы и gameplay правила не меняются. Rojo live остаётся выключен; установка и engine save проверяются отдельно.

Две кнопки в прежнем CornMovementHud над выносливостью: Звук1 и Звук2. Обычный Alt освобождает мышь; только тогда активен выбор. Карта, захват и Roblox menu блокируют нажатие. Начальный вариант1 сохраняет нынешние шесть клипов, частоту cues, два голоса и естественные хвосты. Вариант2 использует один непрерывный MP3 автора; уже звучащие короткие хвосты заканчиваются, новые собственные cues учитываются без проигрывания. NPC продолжают прежнее представление. Возврат к1 ждёт свежего cue и не проигрывает историю.

Новый ключ AudioAssets.COC_Corn_Continuous_02 — настоящий rbxassetid://138698164682825, Duration11.064/Gain1. Root уже проверил отдельный owned tempSound в правильной Children_of_corn Edit: AssetFetchStatus.Success/IsLoadedtrue/TimeLength11.064 и cleanup. Это decoder-проверка, не приёмка игрового воспроизведения или человеческого микса.

RoundAudio на прежнем10Hz actor poll публикует strict boolean AudioCornActive на распознанном серверном CornAudio_corn_rustle только при изменении. Он требует допустимого состояния, настоящего горизонтального движения без телепорта, grounded и нахождения в corn вне реальных CornLayout exclusions. Вычисление независимо от nextAt короткого cue и занятости server Sound. Никаких клиентских запросов для выбора/позиций/длительности нет.

Второй проигрыватель — единственный local SoundService.CornPersonalAudio.CornLoop, owned/project/AudioVersion1, audio_role=cornloop, Effects group. Первое допустимое движение — Play; после остановки — Pause и затем Resume с прежней engine TimePosition. Looped обходит полный клип без ручных seek/restart. Speed1 на ходьбе и1.5 только при серверном is_sprinting=true. Дорога/просвет/воздух/поимка/меню/терминал/retry/потеря или замена Root приостанавливают loop и сохраняют курсор сеанса. Общие stop/preload ветки направляют этот role в Pause. Неизвестные URI/Looped/group/parent/ownership запрещают записи и сохраняются при Destroy. Никаких новых plant scans/world/camera writes.

Наблюдаемые runtime данные: CornMovementHud.RustleMode=1|2, RustleSound2Available boolean, кнопки RustleSound1/2; собственный Root.CornAudio_corn_rustle.AudioCornActive; настоящий CornLoop.IsPlaying/TimePosition/PlaybackSpeed и события Played/Paused/Resumed/DidLoop. GUI attributes меняются только вместе с состоянием. Неподготовленный или отказавший asset имеет явное недоступное состояние; поздняя успешная загрузка возвращает доступность без автоматического replay.

## Фактический production Play: PASS, сохранение ожидается

Root установил ровно5изменённых Sources в правильной Children_of_corn. Новый production CornLoop действительно IsLoadedtrue/TimeLength11.064. Native Start/Confirm прошли; попытка кнопки2 без Alt оставила mode1/Activefalse, после Alt реальная кнопка выбрала mode2/Activetrue. GPU показывает обе кнопки и выделенный вариант2. Для маршрутов использовалась диагностическая постановка в подходящий участок; это не обычный слепой раунд.

Реальные input/property наблюдения root: W2.1сек переместил персонажа на25.2studs; после остановки loop.IsPlayingfalse, AudioCornActivefalse и TimePosition2.283. За следующую1.1секунду неподвижности курсор остался ТОЧНО2.283. W1.7сек продолжил до3.883 при playingtrue/PlaybackLoudness20.37. Shift2.2сек дал PlaybackSpeed1.5/WalkSpeed18/курсор7.243/PlaybackLoudness29.79; отпускание Shift вернуло PlaybackSpeed1, остановка сохранила9.131. Следующее W4сек показало обход конца11.064 и курсор2.206. После диагностической постановки на дорогу native W1.6сек оставил курсор ТОЧНО2.206/playingfalse/AudioCornActivefalse. Native Alt/кнопка1 переключили назад; во время W4.5сек и последующей остановки2.6сек loop остался paused с2.206.

Первый read-only event observer не смог опубликовать отчёт: JSON280302символа превысил200000-предел StringValue. Его event connections уже были отключены до ошибки записи. Поэтому первый прогон подтверждается перечисленными фактическими свойствами и input-результатами, но его потерянный отчёт НЕ доказывает числа Played/Stopped/DidLoop и не используется для утверждения «ноль Stop». Исправлен только тестовый observer: выборки публикуются отдельными массивами по200 в дочерних StringValue, затем малый metadata. Production Sources из-за ошибки отчёта не менялись.

Повторный настоящий observer успешно сохранён: [native-observer.json](../.artifacts/playtests/2026-10-15-rustle-comparison/native-observer.json),1632выборки в9частях. В его интервале5событий Resumed,5Paused,1DidLoop и0Stopped у production CornLoop; первое начало произошло до этого observer, поэтому число Play первого запуска он не подтверждает. Зафиксированы PlaybackSpeed1 и1.5, максимальный PlaybackLoudness156.530179. Два собственных коротких голоса суммарно дали7Play/7natural Ended/0Stop, в том числе native переключение во время звучащего короткого хвоста. Это подтверждает естественное окончание этих наблюдавшихся хвостов; отчёт относится к собственным привязанным голосам данного интервала, не ко всем NPC или всему сеансу.

Точные состояния: [native-properties.json](../.artifacts/playtests/2026-10-15-rustle-comparison/native-properties.json).

Изменения gameplay во время приёмки ограничены явно указанной диагностической постановкой; observer читает состояние и управляет только собственными тестовыми отчётами.
