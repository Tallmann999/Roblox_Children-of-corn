# Три режима освещения перед раундом

## 0. Паспорт документа
`lighting_modes`, «Дети кукурузы», локальный solo PC, версия 0.1, 2026-10-10. Владелец автор проекта. Статус: tested (Studio; saved). Связи: [индекс](feature-index.md), [концепт](project-concept.md), [архитектура](architecture.md). Запрос: большой стартовый экран и три карточки/превью, без изменения правил охоты.

## 1. Саммари фичи
Перед новым раундом игрок выбирает Легко — день, Средне — сумерки и факелы, Сложно — ночь с небольшим туманом. Карточки заранее объясняют разницу видимости. Поиск, две попытки и награда общие.

## 2. Бизнес-контекст
Автор хочет сам выбирать свет/видимость вместо единственного ночного профиля. Это полезно сейчас для локальных плейтестов карты. Три явных варианта отражают запрос; меню с длинными настройками не нужно для первого выбора. Монетизации/публикации нет.

## 3. Цели
Понятный выбор и корректный старт с выбранным освещением. Не усложнять правила монстра, экономику и геометрию. Названия «Легко/Средне/Сложно» обозначают только сложность обзора.

## 4. Метрики успеха
3/3 профиля запускаются мышью и различимы; повтор/меню сохраняют корректное состояние; неверный запрос не меняет свет; 0 новых ошибок проекта. Guardrail: скорость/15 секунд/две поимки/награда и карта идентичны между режимами. Визуальное предпочтение и поиск 7–10 минут оцениваются обычным прохождением позже.

## 5. Позиционирование в системе проекта
MVP расширение стартового/результатного экрана, зависит от round_ui_restart и sound_and_atmosphere (световой части). Выбор действует на весь раунд, включая первую поимку и результат.

## 6. Scope (In / Out / Future)
In: три карточки с небольшими 3D-изображениями поля над кнопками выбора, отмеченный выбор, старт/повтор, HUD режима, дневной свет/сумерки/ночной туман. Out: изменение монстра, таймера, наград, покупок, карты и мини-карты. Future: мобильное управление после отдельного согласования.

## 7. Use Cases / УФЧ
Первый вход: карточки и общий «Начать», игрок выбирает режим и запускает. Повтор: тот же выбор предложен снова, его можно изменить до «Ещё раз». Меню возвращает исходный авторский свет. Неверный запрос не начинает раунд и не изменяет освещение.

## 8. Сущности
Режим: easy/medium/hard, имя, описание, свет/туман, использование факелов. Локальный выбор может отличаться от подтверждённого режима, пока старт не принят. Подтверждённый режим закреплён за раундом.

## 9. Логика работы
Выбор только до start/retry. Сервер проверяет значение и фазу, запускает прежний раунд. Подтверждённый режим показывается в HUD. Первая поимка не меняет режим. Повтор применяет новую выбранную карточку. Результат сохраняет свет; menu/уход владельца возвращает исходные параметры. Stop возвращает сохранённую Edit-сцену. Easy выключает эффекты факелов, шесты остаются; medium/hard используют дистанционные эффекты.

## 10. UI/UX
Расширенная карточка 780 × 510 (рабочий размер реализации, подгоняется по viewport), три равных колонки. Дневное/закатное/ночное небольшое 3D-превью, имя, описание, кнопка. Выбранный режим имеет рамку и слово «Выбрано», поэтому выбор не зависит только от цвета. «Начать»/«Ещё раз» запускают выбранный. Предложение: medium выбран по умолчанию; повтор предлагает текущий режим. Загрузка/ошибка выключают действия, caught остаётся компактной карточкой.

## 11. Параметризация / Конфиги
Профили для первого теста — предложения тюнинга: easy 13:30, яркость 2.5, низкая дымка; medium 17:54, яркость 1.6, сумеречный цвет; hard 20:30, яркость 1, лёгкий туман. Существующая Atmosphere учитывается явно, один FogEnd не объявляется дальностью видимости. Автор может уточнить по обычному плейтесту.

## 12. Формулы, Баланс-Переменные И Локализация
### 12.1 Формулы
`card_scale=min(1,(viewport_width-36)/780,(viewport_height-36)/510)` для расширенной карточки. Порогов механической сложности нет. Радиусы эффектов факелов прежние: свет 90, огонь 220, скрытие верхушки 240–320 studs.
### 12.2 Переменные баланса
Предложения профиля: `mode_clock_time` =13.5/17.9/20.5, диапазон 0–24; `mode_brightness`=2.5/1.6/1, >=0; `mode_atmosphere_density`=.08/.18/.27, 0–1; `mode_atmosphere_haze`=0/.4/.8, 0–10; `mode_fog_end`=1500/700/320, больше start; `mode_torches_enabled`=false/true/true. Цвета проверяются по читаемости; это световые параметры, не баланс монстра.
### 12.3 Ключи локализации
`corn_modes_easy/medium/hard` — «Легко/Средне/Сложно»; `corn_modes_easy_desc` — «День · дальний обзор», `corn_modes_medium_desc` — «Сумерки · горят факелы», `corn_modes_hard_desc` — «Ночь · лёгкий туман». `corn_modes_hint` объясняет общие правила, `corn_modes_selected`, `corn_modes_active` сообщают выбор/режим.

## 13. Контекстные системы
Прежние первый вид/Alt/спринт/охота/ключ/ворота/награда. Факелы учитывают подтверждённый свет. Превью маленькие и самостоятельные, не требуют публикации ассетов. Авторские эффекты Lighting/Workspace сохранены в Edit.

## 14. Аналитика и трекинг
Локальный QA журналирует режим, фазу, свойства света/Atmosphere и ошибки. Внешняя аналитика не входит. Оценить читаемость карточек и мира на текущем тестовом ПК.

## 15. Edge Cases и исключения
Отсутствующий/неизвестный/табличный режим: отказ. Start во время active/caught/preparing: отказ. Повторный start не меняет текущий свет. Первая поимка сохраняет выбор. После menu возвращаются исходные значения всех существующих Atmosphere; их наличие не обязательно. Не закрывать вручную изменённые вкладки скриптов автоматически при установке.

## 16. Риски и митигации
Название сложности может обещать иной ИИ: подпись говорит, что правила общие. Ночь может оказаться слишком тёмной: сверить реальные параметры и изображение, затем плейтест. Изменение авторского света: только Play с восстановлением точных исходных свойств. Карточки на небольшом PC viewport: автоматический масштаб.

## 17. Acceptance Criteria / QA
Обязательны реальные старты каждого профиля, визуальный UI, дневные/сумеречные/ночные параметры и факелы, malformed/active request, retry со сменой, menu restore, первая поимка, прежняя задержка/ресурс/карта, Stop/Edit сохранение. Фактические результаты: [отчёт](2026-10-10_lighting-modes-playtest.md), карточки/старты/повторы/параметры/отказ/поимки/восстановление PASS; полный обычный поиск и FPS остаются открытыми.

## 18. План релиза
Локальная Children_of_corn, code-only guarded update после backup/source проверки, затем Studio engine-save с точным сравнением исходного мира/Terrain. Без live Rojo и публичной публикации. Откат — резервная копия до фичи.
