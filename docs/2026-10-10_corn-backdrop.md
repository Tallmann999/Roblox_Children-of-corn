# Дальний клиентский слой кукурузы

Дата: 2026-10-10. Контракт до реализации; локальный solo PC DEV Studio, только runtime клиента. Авторская карта 840, Ground/Baseplate, исходный арт и сохранённые overview/preview не меняются. Rojo остаётся остановлен.

`CornBackdropController` Order=45 создаёт собственный `CornMap/CornClientBackdrop` Folder. Атрибуты: `CornClientBackdropOwned=true`, `CornEditorOverview=true`, `corn_project_id=children_of_corn`, `Ready=false`, `Stride=2`, `DetailStride=6`, `MaxPlants=20000`. Количество ограничено 20000 растений. Константа Stride=2 использует ту же сетку CornLayout с базовым шагом3, то есть дальний шаг6; альтернативный Stride=3/шаг9 может быть выбран автором после engine QA. Координаты, просветы, Props/spawn/gate exclusions, yaw/height variation и нормальный aspect ratio берутся из CornLayout. Только новые клоны получают CastShadow=false. RenderFidelity наследуется от подготовленного шаблона (текущий Automatic); LocalScript не меняет это свойство. Камера и retry не перестраивают этот слой.

Сборка на Heartbeat: максимум18 клонов и проверка бюджета2мс до следующей ячейки. Неделимая операция клонирования может завершиться после границы бюджета; фактическое время измеряется engine QA. Exclusions/положение и размеры FieldZone/подготовленный шаблон проверяются раз в секунду. При изменении inputs старая сборка прерывается epoch, собственный слой удаляется, исходная видимость возвращается и запускается новый. Чрезмерный размер поля, невалидные inputs, отсутствие bridge или неизвестное совпадение имени оставляют сохранённый overview как fallback.

Публикация слоя атомарна без yield: `CornController:UseBackdropReady(folder)` сначала восстанавливает его прежнюю маску сохранённого overview. После успешного bridge backdrop сохраняет текущие LocalTransparencyModifier всех строго owned оригиналов и скрывает их только локально; затем выставляет Ready=true. CornController связывает ближайшую coverage mask с новым готовым runtime слоем. До Ready сохранённый overview не скрывается целиком. Перед reset/Destroy bridge освобождает маску runtime слоя, Ready снимается, исходные LTM восстанавливаются точно. Сохранённая Transparency/Size/CFrame не меняются.

Именные коллизии и foreign содержимое не удаляются. Cleanup удаляет только созданный этим контроллером, полностью распознанный owned слой; при изменённом ownership или foreign потомке он сохраняет неоднозначный контейнер, возвращает fallback и сообщает отказ. Stop Studio удаляет всё клиентское runtime; Destroy отключает Heartbeat.

CornLayout пропускает строго owned CornClientBackdrop при обходе авторских exclusions. Иначе полный декоративный слой давал бы дорогое сканирование десятков тысяч Parts. Реальные FPS/время сборки и выбор6/9 остаются за engine QA; генерация кода не подтверждает производительность.

Фактическая локальная проверка `lune run tests/corn-backdrop.luau`: PASS. Реальные методы контроллера в ограниченном геометрическом адаптере проверили18 клонов, остановку цикла по искусственным часам2мс, exclusions, неизменный X/Z, нормальную высоту, handshake, reuse, отмену при изменении geometry, caps, сохранение чужих контейнеров и Disconnect. Это не запуск renderer Roblox и не измерение FPS.

Текущая MVP привязка требует подготовленный BasePart (фактический MeshPart). Model template отвергается с восстановлением fallback: near-field coverage принимает прямые BaseParts и не может безопасно маскировать Model-клоны. Lune fixture подтвердил отказ после уже готового слоя, удаление только собственного backdrop и восстановление авторского LTM без изменения исходного Model/арта.

Живой запуск выявил ограничение capability PluginOrOpenCloud для setter MeshPart.RenderFidelity: контекст MCP-эксперимента допускал Performance, обычный LocalScript — нет. Runtime setter удалён полностью; сохранённый/подготовленный арт не меняется, клоны наследуют Automatic. Lune fixture проверяет наследование свойства. Производительность Automatic требует отдельного измерения финального LocalScript, результат экспериментального plugin слоя к нему не переносится.
