# Подсказка закрытого выхода без ключа

Дата: 2026-10-12. Контракт до реализации. Автор попросил явный стоп-знак и «Нужно найти ключ» при подходе к воротам без ключа. Только клиентский runtime UI, local solo PC MVP. Workspace/Lighting/арт/Terrain, remotes и gameplay tags не меняются; звуки остаются отложенными.

Новый GateHintController Order86 получает только уже валидированный snapshot через RoundController:SetSnapshot integration. Подсказка допустима лишь при phase=active, has_key=false и gate_open=false, с текущим живым персонажем. Положение читается из публичного owned CornMap/EscapeGate (existing corn_gate tag)/InteractionAnchor. Горизонтальный входной радиус22 studs, удержание до24 для отсутствия мигания на границе; допуск высоты12 относительно anchor. С обеих сторон ворот действует одинаковая дистанция. Якорь/модель могут быть перемещены/повёрнуты автором — положение не закешировано. Missing/unknown binding скрывает подсказку.

Небольшая нижняя панель над выносливостью: красный GUI-векторный octagon с STOP, заголовок «Нужно найти ключ», помощь «Найди ключ в одном из просветов». Панель не Modal, не имеет кнопок, не перехватывает клавиатуру/мышь, не останавливает мир и не закрывает игровой обзор экранной подложкой. Ключ найден/ворота открыты/caught/result/preparing/ready немедленно скрывают её; выход из зоны, смерть/удаление персонажа или binding — на следующем обновлении10Hz. UI масштабируется по viewport. Destroy отключает render connection и удаляет собственный ScreenGui.

Серверный SoloRound:_openGate остаётся единственным владельцем проверки ключа/открытия/победы. Подсказка не делает запросов на сервер, не раскрывает скрытый ключ/NPC, не начисляет награду и не меняет скорость/камеру.

Приёмка: радиусы/height/hysteresis, moved anchor, каждый запрещённый phase, найденный ключ/open gate/dead character/missing gate, неподвижная повторная snapshot, cleanup и отсутствие input bindings. Локальные fixtures и реальный Studio Test фиксируются отдельно; пока результат не заявлен. Root добавляет архитектурную ссылку до установки.

Реализация размещена только в новом GateHintController. Фактический `lune run tests/gate-hint.luau`: PASS — boundary/hysteresis/height, recognized moved anchor, active/key/gate/phase/dead/missing guards,10Hz и Destroy. StyLua и Selene нового Source: PASS,0/0/0. Ограниченный Lune тест не подтверждает реальные пиксели/подход игрока; `tests/studio-gate-hint.luau` проверяет фактический пассивный GUI и управляемые состояния в движке. Root выполняет engine/live acceptance и validated RoundController wiring.
