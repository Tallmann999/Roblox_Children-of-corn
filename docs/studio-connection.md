## Подключение

**Нужен ручной шаг: включить MCP в правильном открытом окне Studio.**

1. В Studio открой только рабочую `D:\ROBLOX\My_Projects\Roblox_Children of Corn\place\Children_of_corn.rbxl`, нажми Stop и Ctrl+S. Окно Speed Monkey не использовать для этого проекта.
2. Нажми Assistant справа на верхней панели Studio (рядом с кнопками совместной работы/аккаунта), затем `… → Manage MCP Servers`. В другой версии меню может называться `… → Settings → MCP Servers`.
3. Включи `Enable Studio as MCP server`.
4. Roblox_Studio уже зарегистрирован в Codex; повторно добавлять сервер или включать Quick Connect для регистрации не требуется. В настройках MCP Codex должна появиться эта запись после перезапуска.
5. Перезапусти Codex, вернись в этот диалог и сообщи, что MCP в Studio включён. В Studio зелёный индикатор показывает подключившегося клиента. До появления инструментов и списка окон живое подключение не подтверждено.

Эти пункты соответствуют [официальной документации Roblox Studio MCP](https://create.roblox.com/docs/studio/mcp), [официальному плагину Roblox](https://github.com/Roblox/roblox-studio-agent-plugin) и [настройке MCP в Codex](https://learn.chatgpt.com/docs/extend/mcp?surface=desktop).

Пример `scripts/studio-mcp-config.example.toml` соответствует уже добавленной секции в `C:\Users\User\.codex\config.toml`. Он оставлен как документация; не копируй его повторно и не заменяй им всю конфигурацию. При регистрации штатный CLI пересериализовал прежнюю настройку node_repl.args; первая попытка была отменена с полным восстановлением исходного файла. Итог добавлен к исходному тексту, затем все прежние значения сравнены в памяти. Проверка PASS.

Не устанавливать старый `studio-rust-mcp-server`: [Roblox рекомендует встроенный сервер](https://github.com/Roblox/studio-rust-mcp-server). Встроенный launcher уже есть на этом ПК. Rojo для доступа к сцене не требуется и остаётся остановлен после прежнего подключения к другой игре.

## Проверка перед первой правкой

Сначала агент выполняет только чтение:

1. `list_roblox_studios`: выбрать окно Children_of_corn и сохранить его `studio_id`.
2. `get_studio_state` для этого ID: подтвердить Edit / отсутствие активного Play.
3. `inspect_instance` для `game.Workspace.CornMap`: проверить `corn_project_id = children_of_corn` и отсутствие маркеров Speed Monkey (`Asmr_Base`, `ASMR_Models`).
4. Только после проверки имени и маркера выполнять правки с этим же `studio_id`. Все последующие инструменты должны явно адресовать его.

До такой проверки нельзя считать живое подключение установленным. Список MCP в настройках и существующий launcher сами по себе не подтверждают доступ к сцене.

## Совместная работа

Ты двигаешь дома, ворота и расстояния в Edit. Я читаю ту же открытую сцену через MCP, делаю согласованные правки объектов/скриптов и проверяю Play. Не меняем одновременно один объект: перед работой называем область изменения. Сохраняем Ctrl+S после принятого этапа; изменения тестовой симуляции не заменяют Edit-карту.

Код в `src/` остаётся исходником проекта. После живой правки скриптов агент должен перенести итог в исходники, выполнить `scripts/check.ps1` и обновить документацию/защищённые установщики. Отдельная синхронизация Rojo не включается автоматически. Это правила данного проекта; MCP не выполняет такое объединение сам.
