Полный результат: 101 новый world node и 1795 изменений свойств/атрибутов, с 2161 нативным guard. Все 156 прежних Sources сохранены. Установщик распознаёт только целое исходное либо целое конечное состояние, отказывает при неизвестных/частичных правках и откатывает собственную запись при ошибке. Первый нативный apply дал `created=101 / changedProperties=1795`; повтор — `0 / 0`.

Размер payload — 3 160 753 байта, SHA256 `26bca1b53c6b1d5e8007aac52502062f37ad5c273c333d66b1f8a9b0700b31f2`. Для MCP использовалась временная передача через `_G`: 40 частей по максимум 80 000 символов с проверкой точного собранного payload. Это транспорт JSON, а не новые production Sources; весь транспорт удалён после Stop. Повторять следует полный проверяемый workflow, а не частичный старый installer.

Состав workflow:

1. [build-maze02-layout.py](../scripts/build-maze02-layout.py) — фиксированный граф, координаты и геометрические проверки.
2. [plan-maze02-world.py](../scripts/plan-maze02-world.py) — явные reversible world deltas из свежего нативного снимка.
3. [build-maze02-payload.py](../scripts/build-maze02-payload.py) — закрытый payload со Source/world/editor guards.
4. [maze02-native-core.luau](../scripts/maze02-native-core.luau) и [install-maze02.luau](../scripts/install-maze02.luau) — установка только в проверенной stopped Edit B через MCP.
5. [verify-maze02-copy.py](../scripts/verify-maze02-copy.py) — строгий read-only аудит будущего engine Save.

Сохранённый sparse editor overview по-прежнему приблизительный и местами показывает старый просвет дороги. Маски скрывают точные растения на новых тропах; обычный Play заново строит кукурузу по полному актуальному набору исключений. Полная пересборка editor overview в этом этапе не выполнялась.

Сцены не пересериализуются и байты не продвигаются автоматически. Новые ручные изменения автора следует сохранить и отдельно разобрать, а не удалять ради прохождения проверки.
