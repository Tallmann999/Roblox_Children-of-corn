## Один ручной шаг в открытой Studio

Прямой доступ к живому DataModel через Roblox Studio MCP в текущей сессии отсутствует. Скрипт `scripts/remove-corn-from-speed-monkey.luau` подготовлен для Command Bar в режиме Edit:

1. В окне **New_+1 speed monkey** нажать Stop; в Rojo нажать Disconnect.
2. Скопировать весь скрипт очистки в Command Bar и выполнить.
3. Убедиться, что Output сообщает `ChildrenOfCorn cleanup: removed 3 verified containers; Speed Monkey retained`; сохранить сцену и запустить F5. Старт должен вернуться к обычной игре Speed Monkey, без CornPrototypeRuntime и поиска ключа.

Скрипт проверяет исходные маркеры Speed Monkey и полное содержимое всех 15 скриптов/дерево трёх добавленных контейнеров перед любым удалением. Изменённые Sources и дополнительные пользовательские объекты вызывают отказ до удаления. Проверенная модель Corn, временный runtime и два его remotes удаляются при наличии; чужие remotes сохраняются. В Children_of_corn скрипт отказывается работать. Остановка Test убирает созданный только на клиенте интерфейс CornRoundHud.
