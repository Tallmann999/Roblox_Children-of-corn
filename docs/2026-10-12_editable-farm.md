# EditableMesh фермерских ассетов: восстановление после сохранения

Дата: 2026-10-12. Автор явно выбрал EditableMesh. Scope: восстановить предоставленные FBX geometry/UV/normals/colors только у распознанных MeshParts фермерских шаблонов и размещений, не менять authored transforms, размеры, appearance или gameplay. Cloud mesh upload не выполняется: CreateAssetAsync в текущем движке недоступен. Parent проверил создание Tyre EditableMesh/Content.Object в серверном MCP; серверный Object не дал видимого клиентского изображения, поэтому оба peer строят свои локальные EditableMesh из одних сохранённых neutral данных. Это не успешная GPU/render/FPS приёмка.

Контракт ДО реализации: shared Sources — FarmEditableMeshBuilder и четыре JSONDecode ModuleScripts Game/FarmGeometryData с ключами SM_Bld_Barn_03, SM_Prop_Truck_Rusted_01, SM_Prop_Tyre_01, SM_Prop_Rubbish_Pile_05. Geometry data не содержат hidden key/NPC/state и не меняют remote. Ещё два server Sources — Game/FarmGeometry и Services/FarmGeometryService Order15, после Network10 до Round30; Init синхронно выполняет Ensure и сообщает явную ошибку до игрового старта при невозможности восстановить required owned geometry. Client FarmGeometryController Order40 восстанавливает rendering на тех же Props MeshParts собственными клиентскими EditableMesh. Политика solo PC Studio DEV остаётся. Первоначальные +8 Sources:33→41 заменены chunked data контрактом после реального отказа Source setter (предел200000 символов). Каждый AssetKey теперь ModuleScript init с child ChunkNN строками;19 chunk Sources добавляют итоговые27 Sources:33→60. Runtime catalog interface не меняется.

World binding: ServerStorage/CornFarmAssets — Folder с CornFarmAssetsOwned=true и corn_project_id=children_of_corn; его direct Model children имеют Name=AssetKey, CornFarmAssetOwned=true, тот же project. Props Model names: HouseWest/HouseEast/HouseNorthWest для Barn; RustedTruck; Tyre_<integer>; RubbishPile_<integer>. Модель имеет CornFarmAssetOwned/project/AssetKey. Её direct MeshPart children имеют CornFarmMeshOwned=true/project/AssetKey/MeshIndex (1-based внутри dataset). Чужие unowned модели/части не меняются. Owned malformed metadata, unknown asset, nested/outside binding, ручной URI mesh или несовместимая fidelity останавливают восстановление, сохраняя текущее содержимое.

Shared builder сохраняет baked raw FBX coordinates: центрируется только mesh geometry; loader не вычисляет authored позицию или scale и не переносит target. Neutral arrays проверяются целиком до выделения meshes: конечные Vector3/UV/RGBA, bounds, counts ≤60k vertices/20k triangles, все triangle/corner indices, 4 dataset/10 mesh limits. Построение уступает scheduler после500 операций. По одной EditableMesh и непомещённой canonical MeshPart на distinct AssetKey/MeshIndex; все нужные canonical строятся до изменения первого target. Content.fromObject и CreateMeshPartAsync не создают Cloud asset. EditableMesh/canonical удерживаются cache до Destroy.

Canonical создаётся с текущими CollisionFidelity/RenderFidelity target; peer не присваивает restricted fidelity setters. Копии одного mesh должны иметь совместимые fidelity; FluidFidelity canonical должна совпадать. ApplyMesh меняет внутреннюю mesh/physics representation; server сохраняет authoritative collision, client строит соответствующую локальную геометрию для rendering. Прежние значения CFrame/Size/PivotOffset/TextureID/TextureContent/Color/Material/MaterialVariant/Transparency/Reflectance/Anchored/CanCollide/CanTouch/CanQuery/CastShadow/DoubleSided/CollisionGroup/Massless/CustomPhysicalProperties возвращаются точно. Snapshot берётся после await/builder yielding непосредственно перед ApplyMesh, чтобы ручное перемещение/texture edit во время построения не откатились к старой позиции. Parent/Names/attrs/tags и unrelated world не меняются.

Ensure повторно проверяет targets; восстановленный текущим cache Object пропускается, новые/потерявшие geometry экземпляры используют тот же cache. Повтор не добавляет новые world parts или placements. Concurrent Ensure запрещён явной busy ошибкой. Перед применением проверка binding повторяется; Clone snapshots обеспечивают rollback прежней mesh representation+свойств при ошибке ApplyMesh. Destroy очищает unparented canonicals/EditableMeshes; во время active gameplay Destroy не вызывается, поскольку targets ссылаются на эти объекты.

Проверка: meaningful Lune API/geometry adapter должен выполнить настоящий builder на10 исходных mesh/16226 triangles, stable vertex/corner IDs, budgets, cache/repeat/new instance, точное свойство preservation, late author edits, foreign/URI/malformed zero-write refusal, create/apply failures/rollback и cleanup. Это не GPU/Roblox permissions/replication acceptance. Parent отдельно проверяет real ServerScript+LocalScript, actual visible client triangles/texture, reopen saved file, коллизии/проходимость сарая и gate/key/exit loop. Sources и metadata сохраняются в exact engine .rbxl; ephemeral Object pointer не считается постоянным mesh asset.

API ApplyMesh переносит MeshContent/TextureContent и связанную внутреннюю физику, включая fidelity/MeshSize; поэтому нужные settings задаются через CreateMeshPartAsync и возвращается appearance snapshot. Источник: [Roblox MeshPart API](https://create.roblox.com/docs/reference/engine/classes/MeshPart#ApplyMesh).
