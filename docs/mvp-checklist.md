## Полный MVP — игровые фичи

| feature_id | Минимальная приёмка | Статус |
|---|---|---|
| cornfield_map | Постоянная редактируемая карта 1200 × 1200, 15 доступных просветов, выход, полезный ограниченный обзор | Repair installed / Studio acceptance pending |
| key_and_escape | Один ключ, E-подбор/ворота, победа только в выходе; дома не содержат ключ | Repair installed / Studio acceptance pending |
| round_ui_restart | Цель, ключ, исход, повтор без старых состояний; попытки/выносливость после своих этапов | Partial / Test pending |
| session_diamonds | +10 один раз за побег, 0 за другие исходы, баланс до остановки Test | Repair installed / Studio acceptance pending |
| first_person_movement | Первое лицо; спринт 4 с / восстановление 6 с; прыжок без дополнительного расхода | Planned |
| scarecrow_hunt | Активация 15 с, предупреждение, патруль/погоня и выполнимый уход | Planned |
| second_chance | Первая поимка роняет ключ и возвращает на старт; вторая завершает раунд | Planned |
| sound_and_atmosphere | Шелест, направление, рычание, приглушённый день и туман | Planned |
| core_round | Полный цикл, ac_01–ac_20 и протокол новых игроков | Planned |

После карты/ключевого цикла: первое лицо и выносливость → монстр через 15 секунд и две попытки → звук/атмосфера → полный плейтест. Ручные действия: [карта и передача](map-editing-and-sharing.md), [первый игровой тест](first-slice-playtest.md). P1/P2 остаются отложенными.
