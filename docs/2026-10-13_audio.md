Scope: существующий локальный solo Studio прототип, новая звуковая фича. Мультиплеер, публикация, постоянная экономика и меню настроек не добавляются. Server authoritative gameplay сохраняется. Проигрыватели runtime owned и очищаются; постоянная геометрия/Lighting/imported art/Terrain сохраняются.

Уточнение автора14октября заменяет прежний restart каждые0.45сек: каждый начатый corn rustle доигрывается полностью. Сервер на10Hz проверяет живого actor, фактическое горизонтальное движение, grounded, corn field/exclusions и NPC patrol/chase; teleport не считается шагом. Для принятого старта сервер публикует атомарный `AudioRustleStart="id:key"` на прежнем owned server corn Sound, где id строго возрастает, key входит в whitelist шести клипов. Ни координаты, ни факт движения, ни окончание/выбор клипа не приходят новым клиентским запросом. Минимальный серверный интервал стартов остаётся0.45сек; client completion не определяется server IsLoaded/IsPlaying.

Существующий AudioController поддерживает максимум8player actors+1NPC, один owned local shadow Sound на существующем Root каждого actor и только один latest pending cue. Он приглушает ровно распознанный owned server corn Sound; прежняя громкость сохраняется и восстанавливается только при прежней identity/ownership и неизменном локальном mute. Чужие звуки не приглушаются, исходный server Sound/Root не удаляются. Client shadow пространственный; отдельная local очередь не накапливает пропущенные старты.

Остановка после короткого движения, прыжок, дорога/выход из corn, trapped и caught запрещают новые серверные cues, но не обрывают уже звучащий local rustle. Следующий подтверждённый pending cue начинает звучать только после естественного `Ended` текущего shadow: без overlap, таймерного Stop и дополнительной случайной паузы. Latest pending заменяет более старый ожидающий cue.8сек decode fallback относится только к попытке, которая ни разу не начала звучать; он не обрезает длинный воспроизводимый клип. Death/Root replacement/terminal/retry/Destroy очищают owned shadow, pending cues и connections с guarded volume restore. Стандартные Running/Climbing с action_footsteps_plastic.mp3 по-прежнему подавляются клиентом, без удаления штатного скрипта/звуков и без подавления прыжка или смерти.

Только новые старты внутри кукурузы, без дороги/просветов/сараев/воздушного движения; teleport не считается шагом. Spatial range сохраняется; фактический multiplayer не проверяется этим solo этапом.
