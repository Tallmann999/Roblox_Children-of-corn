# Звуки игры

Автор предоставил16файлов в D:/Desktop/Дети кукурузы и выбрал Fon2. Открывание/питьё объединены в adrenaline can open.mp3. Активные15клипов сохраняются как подготовленные MP3 в assets/audio/roblox-import; оригиналы не меняются, SHA/duration/loudness записываются в prepared-manifest.json. Fon1 не используется. Импорт выполняет автор; SoundId в игре должен быть настоящим Roblox asset ID, упаковка RBXL/RBXM не встраивает аудиопоток. Требования: [Roblox audio assets](https://create.roblox.com/docs/audio/assets).

Scope: существующий локальный solo Studio прототип, новая звуковая фича. Мультиплеер, публикация, постоянная экономика и меню настроек не добавляются. Server authoritative gameplay сохраняется. Проигрыватели runtime owned и очищаются; постоянная геометрия/Lighting/imported art/Terrain сохраняются.

Уточнение автора13октября: шелест при ходьбе должен звучать чаще; стандартные шаги Roblox отключаются. Клиент подавляет только штатные Running/Climbing с action_footsteps_plastic.mp3 на персонажах, в том числе после respawn, без удаления штатного скрипта/звуков и без подавления corn rustle, прыжка или смерти. Серверные corn клипы чередуются без тишины между ними, с ограниченным периодом повторного старта при продолжительном движении; неподвижный персонаж, телепорт и дорога по-прежнему не звучат.

- Личный фон2 и Enemy Hunt на клиенте. Музыка погони играет только у серверной цели, начинает тихо и плавно набирает громкость; потеря погони снижает громкость до0 и останавливает трек. При caught музыка прекращается сразу.
- Три Monster Spider — пространственные server Sound на Root монстра, только chase; случайные интервалы и отсутствие одновременных голосов. Capturing/trapped/patrol прекращают голос. Дальность ограничена, дальний игрок его не слышит.
- Шесть corn rustle — случайные пространственные короткие клипы на серверных персонажах и движущемся NPC. Только внутри кукурузы, без дороги/просветов/сараев/воздушного движения; перемещение после телепорта не считается шагом. Источник слышат окружающие. Нет обхода всех растений на каждом кадре: CornLayout exclusions читаются при подготовке раунда.
- Сверчки в пяти невидимых runtime точках поля. Каждый цикл15секунд звучания/15секунд тишины, старты сдвинуты между точками; расстояние ограничено.
- Тихий fire на всех27распознанных факелах в medium/hard; easy гасит звук вместе с огнём. Только owned Sound additions под имеющимися Flame, без изменения исходной геометрии/света.
- Использование предмета звучит только после существующего серверного inventory.use.id: открывание/питьё energy и постановка trap. Initial sync не проигрывает историю, дубликаты id не запускают повтор, caught/terminal/retry/reset очищают звуки.

Общий уровень подготовленных файлов около-20LUFS, с запасом по пикам; категории/громкости и distance/fade/timers вынесены в shared AudioRules. Music/Ambience/Effects/SoundGroups дают будущему меню настройки отдельные регуляторы; само меню позже. Ни одного нового клиентского запроса/remote для проигрывания мировых звуков: сервер считает movement/state сам. Monster runtime получает ChaseTargetUserId,0 вне chase, ID владельца при chase; это identity цели, не координаты для мини-карты. Клиентская музыка дополнительно требует личный active/chase snapshot.

Перед завершением нужны реальные IsLoaded/TimeLength/playback measurements в правильной Studio, authority/cleanup/cycle/fade tests, Source equality, строгая проверка сохранённого engine файла и backup. Наличие кода без настоящих доступных asset IDs не означает готовый звук.
