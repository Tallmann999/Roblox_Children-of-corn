# Маркеры игрока и выхода на мини-карте

Дата: 2026-10-12. Автор запросил более вытянутую прямоугольную голубую стрелку игрока и синий квадрат ворот выхода. Изменение ограничено клиентским runtime UI и чтением существующей авторской геометрии; карта, исходный арт, сохранённые размеры/CFrame, Lighting и Terrain не меняются. Текущий MVP — local solo PC, Rojo остановлен, звуки ждут подборки автора.

Контракт до реализации: compact и expanded используют один стиль маркеров. Игрок — вытянутый прямоугольный shaft с явным direction tip, цвет RGB(94,220,255); Rotation по прежнему Heading текущего FieldZone и HumanoidRootPart.LookVector. Ворота — синий квадрат RGB(61,121,255), позиция существующего публичного CornMap/EscapeGate/InteractionAnchor (GateInteractionAnchor в серверной привязке). Чтение только recognized CornMap/project, tagged corn_gate Model и BasePart anchor; при отсутствующем/невалидном binding квадрат скрывается. Текущее положение и поворот FieldZone/ворот читаются при прежнем обновлении10Hz, поэтому ручное перемещение до Play учитывается. Координаты вне поля ограничиваются краем прежней проекцией; UI отступ учитывает размер маркера.

Ворота видны всякий раз, когда показана карта, включая результат раунда; их закрытое/открытое состояние не меняет маркер. Живая стрелка сохраняет прежние phase/character правила. Скрытый ключ, NPC и непосещённые ориентиры не отображаются. Новые remotes, tags и world объекты не добавляются. Серверная история посещений/смертей и M/Alt/Esc lifecycle не меняются.

Обязательная проверка: обе карты, четыре направления, вытянутый shape/контраст, край поля, преобразование при перемещении/повороте FieldZone и ворот, отсутствие gate binding, сохранение visits/deaths и cleanup. Локальные fixtures проверяют реальные методы без изменения авторского Workspace. Фактический Studio рендер и визуальное подтверждение выполняются root; пока не заявлены.

Реализация: PlayerArrow — Frame16×30 (compact) или20×37.5 (expanded), прямоугольный Shaft и triangular Tip из семи GUI-полос; поворот не зависит от clipping или шрифтов. ExitGate — квадрат10/15px. Легенда большой карты различает голубую стрелку и синий выход.

Фактическая локальная проверка `lune run tests/minimap-gate-binding.luau`: PASS — текущий gate binding, перемещённый/повёрнутый field/anchor, невалидный/отсутствующий anchor/tag/project, чужой field и отсутствие записи CFrame/Size. StyLua/ Selene по двум изменённым клиентским файлам: PASS, 0 ошибок/предупреждений/parse. Ограниченный Lune-адаптер не проверяет pixels Roblox; `tests/studio-minimap-markers.luau` добавлен для actual GUI, четырёх направлений, обоих представлений, edge inset, истории и cleanup. Его engine запуск выполняет root.
