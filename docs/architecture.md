# Дети кукурузы — архитектура

2026-10-09. Текущий этап: постоянная редактируемая карта 1200 × 1200 studs и проверка ключа/ворот/выхода/повтора. Пользователь подтвердил очистку ошибочного подключения к Speed Monkey и разрешил продолжить только в Children_of_corn. Живая приёмка нового этапа остаётся открытой.

## Владение сценой

- Рабочая сцена: `place/Children_of_corn.rbxl`. Все операции установки проверяют её маркеры и отказываются при наличии маркеров Speed Monkey.
- Workspace/Terrain/Lighting и импортированный ServerStorage-ассет принадлежат автору. Rojo по-прежнему отображает только GameShared/GameServer/GameClient. Live sync остановлен; новую карту переносим одним защищённым установщиком или в отдельной проверенной копии файла.
- Пользователь явно разрешил постоянный CornMap для ручного редактирования. Прежний CornPrototypeRuntime 120 × 120 заменяется привязкой к готовой сцене. Иные пользовательские объекты не удаляются.
- Повтор раунда не перестраивает карту. Меняются только собственный временный ключ, состояние ворот и раунда. Остановка Test возвращает Studio Edit-состояние.

## Контракт постоянного CornMap

Workspace/CornMap — Model с `corn_project_id = children_of_corn`, `map_version = 1`. Установка не перезаписывает существующий CornMap: повторная установка отказывается до любых изменений карты.

| Объект | Контракт |
|---|---|
| Ground | Якорный Part, поверхность 1200 × 1200 studs, верх Y = 80 |
| FieldZone | Невидимый Part 1200 × 10 × 1200, центр Y = 85; tag corn_field_zone. Вертикальная ориентация без наклона, кукуруза располагается относительно его CFrame |
| PlayBounds | Невидимый Part 1200 × 50 × 1240, расширяет безопасную проверку до внешнего выхода; tag corn_play_bounds |
| RoundSpawn | Якорный Part, tag corn_spawn, spawn_id = solo_start. CFrame задаёт направление старта (LookVector); высота персонажа вычисляется от верхней поверхности |
| KeySlots | Folder с 15 якорными Parts, tag corn_key_slot, уникальный непустой slot_id. Ключ появляется над перемещённым/повёрнутым слотом |
| EscapeGate | Model, tag corn_gate, gate_id = solo_gate. Door, InteractionAnchor и ExitZone внутри одной Model, перемещаются и поворачиваются вместе |
| Door | Якорный BasePart ворот. Закрытые исходные Transparency/CanCollide/CanQuery сохраняются привязкой; открытие скрывает и выключает только эту часть |
| InteractionAnchor | Невидимый Part на стороне входа; создаваемый на время теста E ProximityPrompt, радиус 4. Передняя сторона определяется локальным Z Door относительно Anchor |
| ExitZone | Невидимый неконфликтующий Part за воротами, tag corn_exit, gate_id совпадает. Победа только при открытых воротах и внутри локального объёма |
| NoCornZones | Folder с якорными Parts-зонами: просветы, старт, ворота, центральный ориентир. Сдвиг/поворот/Size меняют область без декоративной кукурузы |
| Props | Folder; дома и прочие декорации из Parts. Дома — препятствия, ключ ищется только в просветах поля. Автор может редактировать их независимо |
| EditorPreview | Собственная Folder ограниченного предпросмотра кукурузы возле старта. В клиентском Test удаляется только локально и заменяется подгружаемыми растениями |

Слоты сортируются по slot_id, проверяются количество и уникальность. Tags учитываются только внутри данного CornMap. Источник ворот, старт, FieldZone и PlayBounds должны оставаться доступны. Поворот ворот не ломает проверку передней стороны и выхода. Наклоны земли/FieldZone и вертикальные ступени в этом первом этапе не поддерживаются; горизонтальные координаты и размеры редактируются вручную.

## Кукуруза

ServerStorage содержит импортированный `SM_Prop_Plant_Corn_01_L`; допустимый альтернативный явный идентификатор `CornPlantTemplate`. Источник сохраняется целиком и не масштабируется на месте. В сохранённой сцене MeshContent Uri = rbxassetid://104111861186519, TextureContent Uri = rbxassetid://137803536172445.

Game/CornField.Prepare() проверяет art-only источник и создаёт нормализованный клон высотой 8 studs в ReplicatedStorage/CornRuntimeArt/CornPlantTemplate во время Test. При неоднозначных источниках или коде внутри art сообщает ошибку; исходный ассет не меняется. Родитель содержит атрибут принадлежности Corn. Геометрия/UV и texture Uri сохраняются.

Shared Game/CornLayout задаёт шаг 4.5 studs, клетки относительно FieldZone, поворот от индекса клетки и проверку локальных NoCornZones/просветов. Клиентский CornController создаёт ограниченные порции растений рядом с персонажем (~85 studs), удаляет дальние группы. Все растения Anchored=true, CanCollide/CanTouch/CanQuery=false, CastShadow=false. Кукуруза — клиентский декор; серверные ключ, ворота и награда от него не зависят. Полное заполнение 1200 × 1200 при таком шаге требует около 71 тыс. растений; оно не создаётся одновременно. Реальные FPS/видимость/темп ещё нужно измерить в Studio.

Для редактирования предусмотрен ограниченный EditorPreview; предпросмотр выбранной области может пересоздать только свою Folder. Ручные растения и Props не удаляются. Дома исключаются из посадки по footprint Parts (Box); новые ручные сооружения желательно дополнить NoCornZone.

## Lifecycle и игровой цикл

Bootstrap загружает Services/Controllers по Order, Init всех затем Start всех. Services: Network 10, Tag 20, Round 30. Controllers: Corn и Round. Весь игровой код запускается только Studio/DEV/solo_local. Основной игровой мир читает постоянный CornMap; скрытого построения другой маленькой карты больше нет.

SoloRound остаётся серверным владельцем одного игрока, фазы, случайного слота ключа, наличия ключа, ворот, результата и временных алмазов. Клиент занимается интерфейсом и декором. Спринт, первое лицо, монстр и две попытки — следующий этап; сейчас не обещается полный хоррор-MVP.

| Endpoint | Payload |
|---|---|
| request_round_action Client → Server | string: sync/start/retry/abort/menu; token bucket capacity 2, refill 2/sec |
| round_snapshot Server → Client | phase, has_key, gate_open, session_diamonds, reward_diamonds, elapsed_sec, notice |

Фазы: ready/preparing/active/escaped/aborted. Клиент не объявляет победу, не выбирает скрытый слот и не задаёт награду. E-взаимодействие проверяет владельца, фазу, текущего живого персонажа, Enabled, дистанцию 4, луч без твёрдой преграды и для ворот входную сторону. Ключ расходуется при открытии. Пересечение ExitZone живым игроком даёт +10 один раз. Retry возвращает на авторский старт, закрывает ворота, выбирает новый слот и сохраняет баланс; Reset/смерть/уход прерывают раунд без награды.

## Проверка и границы

Нужны format/lint/Rojo build, проверка сохранения пользовательских instances/ассета и локальный Studio Test: карта видна в Edit; кукуруза видна у игрока; передвижение Gate Model работает; пройти ключ → ворота → выход → retry; награда не дублируется. CLI-проверка не заменяет Test. Сцена для тестировщика сохраняет код и карту в .rbxl; Rojo ему не требуется, облачным mesh/texture нужны доступ и загрузка.
