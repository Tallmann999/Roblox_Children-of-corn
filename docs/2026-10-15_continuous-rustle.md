## Представление и авторитет

Собственный игрок использует единственный 2D SoundService.CornPersonalAudio.CornLoop с авторским полным MP311.064секунды. Он автоматически Play при первом движении; затем только Pause/Resume, без ручных seek/restart/Stop. Cursor сохраняется через остановку, дорогу, воздух, меню, поимку, retry и смену Root в пределах сеанса. Собственная скорость сохраняет принятый автором вариант: walk1/sprint1.5 от server snapshot.is_sprinting. Energy не добавляет локальному владельцу отдельный множитель аудио.

Семь возможных других Players и три NPC используют по одному spatial owned local Root.CornLocalRustle, rolecorn_loop_local, с range5..65 и тем же URI/Effects gain. Вместе с собственным Sound максимум11проигрывателей. У каждого собственная TimePosition, Pause/Resume и первый Play; нет общего курсора для разных монстров. Другие Players получают стабильный ratio server Humanoid.WalkSpeed/12, clamp1..2, rounding0.1. NPC используют прежний authoritative hunt._chaseSpeed для chase и balance.monster_patrol_speed для patrol. Если тестовый/неполный hunt не предоставляет их, fallback фактического горизонтального движения/10 округляется0.1 с hysteresis0.15, чтобы waypoint/physics шум не менял высоту каждый poll. Ни клиентский аргумент скорости, ни дополнительный remote не вводятся.

Серверный Root.CornAudio_corn_rustle — silent metadata binding: continuousURI/Volume0/AudioRequestedPlayingfalse, никогда не играет. AudioCornActive и AudioCornSpeed публикуются только при изменении на прежнем10Hz poll после actual movement/grounded/corn/exclusions/неteleport/phase validation. Пауза монстра в trapped/capturing/неподходящей фазе даёт activefalse/speed1. При активном состоянии скорость и движение независимы от исчезнувших коротких cue deadlines.

Старые шесть коротких corn URI сохранены в AudioAssets только как архив. Сервер и клиент больше не создают коротких cues/пула и не запускают эти клипы. Preload пропускает Rules.CornKeys, поэтому из16записей загружаются только10активных assetIDs. Фон/Hunt/голоса/scream/сверчки/Fire/использование предметов и стандартное подавление Running/Climbing сохраняются.

Guarded cleanup распознаёт точные ownership/project/version/name/role/URI/Looped/parent/group. Изменённый foreign loop сохраняется; существующий неизвестный Root.CornLocalRustle блокирует повторное создание. Другие/NPC loops удаляются при terminal/Root replacement после Pause; собственный personal loop сохраняет cursor через раунд и удаляется только при Destroy с прежним foreign guard. Новых plant scans/world/camera/gameplay writes нет.
