# Вариант A: белые глаза и чёрная ночь

Автор выбрал прежнее поле A и подтвердил: факелы оставить. Работа ограничена светом и внешностью врага. Плотный новый fog/частицы/новый renderer тумана не добавляются; существующая дымка только диагностируется. Правила 1–4 игроков, ключ/ворота/deadline, поимки, награды, радиусы 48/96 и аудио не меняются. Отдельный файл B сохраняется без изменений.

## Контракт

- `HarvestWardenVisual`: только Classic/A получает два белых Neon-ядра, два SpotLight (Range60, Brightness2.5, Angle14, Shadowsfalse) и два Beam без внешней текстуры. Лучи расходятся наружу на 7° и вниз на 2.5°, имеют ширину 0.125→5.5 и затухают к концу. Attachment/Beam принадлежат прежнему `HarvestGeometryOwner=harvest_warden_v1` / `corn_project_id=children_of_corn`, вложены в клиентскую внешность под прежним Root. Новых persistent world nodes, коллизий, gameplay remotes или полевых источников красного света нет. Маска поимки/скрытие и cleanup распространяются на лучи. B/Detailed сохраняет прежние красные PointLight.
- `LightingModes`: в активном hard-раунде Brightness/Ambient/OutdoorAmbient/EnvironmentDiffuseScale/EnvironmentSpecularScale=0, GlobalShadows=true. Факелы остаются включёнными. На существующих Sky временно меняются только шесть граней, CelestialBodiesShown и StarCount; исходные значения возвращаются при menu/cleanup. Если Sky отсутствует, создаётся один runtime `CornBlackNightSky` с `CornBlackNightSkyOwned=true` и project attr; удаляется только точный неизменённый собственный экземпляр. Авторские Sky не удаляются.
- Небо использует собственный одноцветный PNG RGB(0,0,0), `rbxassetid://127362238475901`, на всех шести гранях. Пустые URI в native probe оставляли синий горизонт; с реальной чёрной текстурой шесть preload получили Success и GPU показал чёрный фон. Значения Atmosphere/Fog при этом не менялись.
