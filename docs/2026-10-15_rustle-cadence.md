# Более частый шелест — 15 октября 2026

Автор попросил удвоить частоту шелеста при соприкосновении с кукурузой. Полное естественное окончание каждого начавшего звучать клипа остаётся обязательным. Текущий одиночный локальный проигрыватель не позволяет этого добиться одной заменой минимального интервала: сервер ждёт duration/IsPlaying, а клиент — собственный Ended. Поэтому этот follow-up разрешает два ограниченных локальных голоса на actor.

Точные production файлы: существующие AudioRules, RoundAudio и AudioController. Новый cue получает прежний атомарный AudioRustleStart=id:key только после прежней серверной проверки движения, земли, кукурузы, исключений и состояния NPC. Плановый интервал — max(0.45, duration) / 2 секунды при прежнем опросе 10 Hz. Для шести авторских клипов это 0.225–1.03 секунды вместо 0.45–2.06 секунды. При непрерывном допустимом движении deadline продвигается от предыдущего, сохраняя остаток максимум 0.1 секунды. После остановки/air/road/teleport/ineligible следующий cue снова якорится на now. Минимальный следующий deadline — now+0.125; максимум один cue за Step, без догоняющих bursts или накопления пропущенной истории. Статичный actor, прыжок, дорога, телепорт и trapped/capturing NPC новых cues не получают.

Сначала проверенный вариант с привязкой каждого cue к now дал на одинаковом 12-секундном маршруте 18 прежних и 30 новых cues (1.667×), поскольку каждый отдельный интервал округлялся до 10 Hz. Разрешённый ограниченный остаток устраняет накопление этого округления: текущий actual-module adapter на той же последовательности Corn10/Corn02 дал 18 / 36 cues (2.000×). Это счётчик серверных разрешённых cues на детерминированном маршруте, а не обещание точного отношения фактически слышимых начал в любом случайном или сетевом сценарии.

Один существующий server Sound доигрывается прежним способом, без смены URI или Stop ради более частого cue. Когда он занят, новый cue передаётся через metadata, а новый server playback не запускается. Более раннее серверное окончание не управляет клиентским окончанием. Ни одного нового клиентского запроса, remote, Source или постоянной world геометрии.

На клиенте два заранее созданных owned spatial Sound на каждом разрешённом Root. Верхняя граница — 8 игроков и 3 NPC, 11 actors / 22 голоса. При свободном голосе новый cue начинает звучать сразу; каждый начатый голос доигрывает до собственного natural Ended. При двух занятых голосах хранится только один newest pending cue; старые ожидания вытесняются. Новый cue после Ended запускается ближайшим Heartbeat после завершения dispatch. URI активного голоса не заменяется, таймерных Stops нет. Громкость, авторский gain, Effects group, PlaybackSpeed и rolloff прежние; новый второй голос может естественно перекрываться с первым.

Остановка и смена eligibility не обрезают уже начатые хвосты. Смерть, замена Root/источника, terminal/retry/Clear/Destroy очищают оба локальных звука и connections с прежним guarded restore исходного server Volume. Загрузка, которая не начала реально звучать за 8 секунд, освобождается; более старую неудачную попытку нельзя повторять после принятия нового cue. Очередь, retry и число голосов остаются ограниченными.

Локальные тесты должны проверить два onset до первого Ended, неизменный URI каждого занятого голоса, natural Ended advance, newest pending 1, отсутствие новых cues без движения, server playback без обрезания и cleanup всех 22 голосов. Отдельная настоящая Studio Client fixture проверит шесть авторских decoders, фактические TimePosition/PlaybackLoudness/Ended обоих голосов, отсутствие Stop и замены URI до окончания. Локальные адаптеры не являются декодированием или приёмкой человеческого микса. Root выполнит реальное движение и установку; новый save и hash фиксируются отдельно.

До guarded code installation необходимо сохранить fingerprints текущих установленных AudioRules, RoundAudio и AudioController в разрешённой Source history. Build после редактирования не должен потерять установленную промежуточную версию. Исторические engine save и результаты одиночного проигрывателя 14 октября сохраняют своё прежнее значение.
