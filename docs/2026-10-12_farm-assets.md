# Фермерские ассеты из FBX

Дата: 2026-10-12. Scope: Barn03 вместо трёх временных домов, ржавый Truck на дороге под20°, пять шин и три мусорные кучи. Звуки отложены автором. Оригинальные FBX и прежние модели сохраняются.

В assets/farm лежат точные копии четырёх предоставленных FBX. Исходники FBX7400 ссылаются на недоступный внешней PSD PolygonFarm_Texture_01_A_2k.psd. `_textured.fbx` сохраняют все geometry/model/material/connection nodes, добавляют точный текущий PNG atlas и исправляют только FileName/Video content; файл FBX пользователя не меняется. asset-verification.json содержит hashes и проверку различий.

assets/farm/neutral сохраняет baked позиции в сантиметрах, треугольники, UV/normal indices по каждому углу, исходные transforms и world bounds. Все transforms исходников identity; их pivot не вычитается повторно. Triangulation использует ear clipping для вогнутых многоугольников, n−2 проверяется для каждого face. Roblox UV использует1−v; реальная клиентская шина подтвердила рисунок протектора и правильную ориентацию текстуры.

Сарай:7 meshes/8160 triangles; грузовик:1/5936; шина:1/1522; мусор:1/608. Всего10 meshes/16226 triangles. Точный исходный PolygonFarm_Texture_01_A.png: SHA256 ae59540efad76de089c17059762d627caff3a74bc30b64dc497f0a5d855322dd, URI rbxassetid://95855894892409. Общий atlas кукурузы дал неправильный красный фасад и больше не применяется к farm моделям; исходная corn texture не менялась. Human scale: дверь сарая7.5studs, весь сарай примерно20.84×19.42×15.86; yaw−90° открывает исходный вход−X к−Z. Грузовик длиной18studs, шириной6.60; центрX3/Z140, yaw20° оставляет слева проход. Шина диаметром1.8, мусор шириной3.2. Новые props anchored; geometry collision server-authoritative, дверные копии скрыты/CanCollide=false. Бывшие дома сохраняются под ServerStorage/CornFarmSceneArchive без изменения старых instance properties.

[Контракт восстановления](2026-10-12_editable-farm.md): CreateAssetAsync в установленном движке недоступен. Выбранный автором EditableMesh route хранит geometry data в saved Sources и создаёт отдельные объекты на server/client. Это не permanent cloud mesh и не публикация опыта. scripts/install-farm-world.luau — guarded Edit installer с rollback; повтор проверяет ownership и использует cache. Scene сохраняется только точными engine bytes после preservation проверки, без Lune serialization.

Файловые проверки: tests/test_farm_assets.py6 PASS; tests/farm-editable-builder.luau PASS10 meshes/16226triangles, UV/normal corner IDs, смещение центра, yield500 и error cleanup. Реальный MCPP server создал шину, но client rendering серверного Object отсутствовало; реальный client создал и показал корректную шину. Полная установленная farm physics/boot/reopen приёмка фиксируется отдельно в итоговом playtest.
