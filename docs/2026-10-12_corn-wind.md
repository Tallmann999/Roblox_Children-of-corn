# Локальная реакция кукурузы на проход

Дата: 2026-10-12. Новая просьба автора отменяет прежний ветер в hard: весь компьютер сильно тормозил. Постоянного покачивания поля больше нет. Scope — декоративные клиентские копии локального solo PC MVP; сохранённый арт/геометрия, Lighting, серверная охота и остальные правила не меняются. Звуки отложены.

Контракт до реализации: существующий CornWindController, Order55 и SetMode(mode: string?) остаются. В каждом выбранном режиме кукуруза реагирует только на движение около неё. nil/неизвестный режим выключает реакцию и точно возвращает исходные CFrames. Живой движущийся игрок может отклонять не больше двух видимых растений перед собой/при контакте в радиусе5studs. Дополнительно движущийся публичный Monster может отклонять максимум два растения рядом с собой; его участок должен быть виден камерой и находиться в пределах70studs. Это позволяет увидеть локальное движение с пенька. Ни неподвижный игрок, ни стоящий/скрытый/задержанный монстр не создают покачивание. Новых remotes/тегов нет; серверное положение монстра читается из прежнего owned CornRoundRuntime/Monster/Root.

Только собственные CornClientPlants/CornClientBackdrop; исходные EditorFieldOverview, EditorPreview и шаблон не анимируются. Растения Anchored, без CanCollide/CanTouch/CanQuery. Индекс исходных положений создаётся по ChildAdded/Removed, единственному первоначальному чтению контейнера и порциями≤64заHeartbeat с бюджетом1ms. Spatial buckets6studs позволяют выбрать ближайших кандидатов около двух движущихся тел, а не обходить поле. Выбор5Hz, максимум128проверенных записей на тело; анимация12Hz, максимум4растения/32части за обновление. Нет сортировки сотен растений или регулярного полного GetChildren/GetDescendants. Геометрия Model читается только при регистрации.

Короткое отклонение до3° происходит вокруг исходного основания; расчёт всегда от исходных CFrames, без накопления drift. След движения длится максимум0.3секунды после остановки. Невидимые растения и Far с Ready=false точно восстанавливаются. Переход режима, смерть/смена персонажа, уход из радиуса, удаление растения/группы/слоя/карты, потеряownership и Destroy тоже возвращают CFrames. Все собственные связи отключаются при Destroy. Диагностические CornWindMode/CornWindAnimated attributes существуют только на собственных runtime слоях.

Проверка: тест настоящего Source в Lune с реальными CFrame и ограниченным signal/player/camera adapter должен покрыть два ближайших перед игроком, отсутствие движения в покое, отдельный движущийся Monster и обзор сверху, предел4/32, точное восстановление/смену режима/смерть, hidden/Ready, event lifecycle, отсутствие recurring full scans и полное отключение signals. Живое измерение кадрового времени и визуальная приёмка выполняются отдельно в правильной Children_of_corn. Локальный тест не означает FPS acceptance.

Фактический локальный результат: lune run tests/corn-wind.luau — PASS. Выполняется настоящий Source с реальной Lune CFrame геометрией и ограниченным event/camera/player adapter. Проверены два ближайших перед движущимся игроком, отдельные два растения у движущегося монстра, совместный multipart случай ровно4растения/32записи, наклон≤3°/фиксированное основание, zero ambient motion в покое, прекращение реакции после0.3секунды, все три режима, отсутствие реакции dead/trapped, обзор с высоты40, невидимость/уход из радиуса, 12Hz throttle, индекс≤64, поиск≤256записей двух акторов даже при3000дальних растениях, отсутствие recurring GetChildren/GetDescendants, Ready/removal/ownership/map cleanup, восемь переключений безdrift и отключение всехsignals. Отдельный selene Source:0errors/0warnings/0parse errors. scripts/check.ps1 также PASS: форматирование, lint, code-only build, sourcemap, mappings и disabled persistence. Живой клиентский/FPS тест ещё не выполнен этим подзаданием.

Автор подтвердил после установки: «1–5 работают, лагов нет» при проходе hard. Обычный LocalScript измерен с максимум2реактивныхрастения/305кадровсреакцией. Смешанныйfocus50sec FPS не считается чистым benchmark; полный отчёт в inventory-playtest.md.
